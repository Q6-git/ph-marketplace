# 팔렝케 마켓 🛺

필리핀 동네 중고거래 서비스의 **클릭 가능한 시제품**입니다. HTML, CSS, JavaScript만 사용하며 빌드 과정이 없습니다.

## 기능
- 상품 목록: 카테고리, 지역(메트로 마닐라·세부·다바오 등), 정렬, 무료 나눔 필터
- 검색: 제목과 설명에서 찾기
- 상품 상세: 상태, 거래 방법(직거래, LBC/J&T 택배, Grab/Lalamove), 결제 수단(GCash, Maya, 현금)
- 판매자 채팅 (모의 자동 응답)
- 판매 글 등록: 사진 첨부 시 자동 축소, 무료 나눔, 입력 검증
- 찜 목록, 내 판매 목록, 거래완료 표시와 삭제
- 모바일 하단 메뉴, 다크 모드 자동 지원

데이터는 샘플 16개와, 사용자가 등록한 글(브라우저 localStorage에 저장)로 구성됩니다.

## 실행
```bash
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다. `index.html`을 바로 열어도 동작합니다.

## 파일 구성
- `index.html`: 페이지 뼈대
- `style.css`: 디자인
- `data.js`: 카테고리, 지역, 샘플 상품
- `app.js`: 화면 전환(해시 라우팅)과 모든 동작
